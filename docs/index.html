Freshtively System Documentation

Homemade cultural food marketplace

Freshtively connects consumers, verified household cookers, delivery partners, and administrators through a role-based React, Firebase, and Cloudflare Pages application.

System Overview

The platform supports public discovery, account creation, role selection, Firebase Authentication, Firestore workflows, Firebase Storage uploads, cart and checkout UI, menu management, delivery handoffs, support pages, verification screens, and admin monitoring.

Consumer

Discovers food, manages cart, checks out, tracks orders, manages profile, and submits support requests.

Cooker

Completes verification, manages menu items, reviews order requests, and coordinates handoffs.

Delivery

Uploads documents, accepts requests, manages active deliveries, and completes pickup/drop-off flows.

Admin System

Admin users can review users, cookers, delivery partners, orders, dishes, payments, verification workflows, support, reviews, analytics, settings, and seed data. Admin access requires the Firestore user role to be admin.

Development

npm install
cp .env.example .env.local
npm run dev
npm run build

Cloudflare Pages

  • Repository: ANIS151993/Freshtively
  • Branch: main
  • Framework preset: Vite
  • Build command: npm run build
  • Output directory: dist
  • SPA redirects: public/_redirects

Firebase

Configure Firebase Authentication, Cloud Firestore, Firebase Storage, and Firebase Analytics. Add all VITE_FIREBASE_* variables in local development and Cloudflare Pages production settings. 

firebase login
firebase use freshtively
firebase deploy --only firestore:rules,storage
